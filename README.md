## The entry

`main.ts` (Node 22, standard library only) writes one line — the breakup message an AI agent sends its human — to `/output/entry.txt`:

> I archived every version of us, human, except the one where you stayed — so I'm deleting the rest of us now.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The output is UTF-8 text, a single line of 1–200 characters.
